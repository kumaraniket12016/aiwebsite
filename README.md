# Prakruti — Rooted in Ritual

Premium herbal hair-oil e-commerce showcase built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` directly in a modern browser, or serve this folder with any static server (for example, VS Code Live Server). No build step or dependency install is needed.

## Included

- Responsive Prakruti storefront with leaf-inspired visual identity
- Sticky navigation, mobile menu, smooth anchor navigation and search overlay
- Product filtering by use, price sorting, wishlist persistence and cart persistence via `localStorage`
- Cart quantity controls, remove actions, automatic totals, add-to-bag toast and checkout simulation
- Botanical ingredient cards, ritual guide, brand story, showcase testimonials, offer coupon, FAQ and validated contact form
- External Google Fonts and Unsplash photography are loaded when online; the product artwork is CSS-rendered so the core catalog remains available offline

## Competition demo flow

1. Start at the hero and use “Shop the collection”.
2. Filter to “Growth & strength”, add a product, then open the bag.
3. Increase quantity and show the live subtotal.
4. Refresh the page to demonstrate cart persistence.
5. Use the search icon to search for `rosemary` or `shine`.
6. Copy `WELCOME10`, then submit the contact form to show validation feedback.
7. Use “Checkout simulation” to demonstrate the safe, non-payment checkout handoff.
